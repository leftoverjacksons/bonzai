The tree grows inside a ruined shaft. Light reaches it only through windows, gaps between columns and a broken roof, and the beams move as the hours pass. Walls between you and the tree fade away so it stays in view.

Each run blends Atlantean, Angkor and Maya building styles in new proportions: stone colour, carvings, windows, columns, water and the colour of the magic glow all follow the blend. "New run" rolls a new tree and a new blend.
